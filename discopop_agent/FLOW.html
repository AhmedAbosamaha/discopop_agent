DiscoPoP agentic controller

The Restructuring Loop

DiscoPoP profiles a program and reports where it cannot find parallelism. The agent takes those regions to an LLM, which rewrites the source so the parallelism becomes visible — then hands the rewrite back to DiscoPoP to judge. Nothing is kept unless the profiler can parallelize it and the result is measurably faster.

02 One region, followed all the way

The benchmark case array_accumulator, exactly as it ran. It shows the handoff both ways: DiscoPoP gives up, the LLM restructures, DiscoPoP re-judges its own analysis of the rewrite, and Tier 1 finishes the job.

Who writes the pragma, and when

DiscoPoP writes every pragma — its patch generator emits them into .discopop/patch_generator/<id>/. The LLM is forbidden to, and complies: not one Tier-2 patch in the benchmark contains #pragma omp. The agent copies a pragma into your file at exactly one place, _apply_to_source in the Tier-1 branch, after that pragma passes the gate. Verification measures pragmas too, but only inside a temporary directory — it decides whether to keep the rewrite, never what your file contains. --no-apply-patches suppresses the pragma write and leaves only the record.

03 Zoom in · the quality gate

The QUALITY GATE boxes in figure 1, opened up. Both tiers pass through the same five stages, in a temporary directory — the real source is never touched until every stage passes. Two stages are conditional, and the gate reports which ones it skipped rather than implying they passed.

The trap this design avoids

Reducing OMP_NUM_THREADS to 4 made ThreadSanitizer far faster still — and the same real race then went undetected on two runs out of two. Detection is probabilistic; a gate that passes because it looked less hard is worse than a slow one. Only the redundant work after the first report was removed.

04 Zoom in · what the two sides say

The L2 and L3 boxes in figure 1, opened up. The channel is deliberately lopsided. DiscoPoP sends nine signals, each traceable to a file it wrote. The model sends back exactly one thing — restructured source — and the profiler re-derives everything else itself.

05 Zoom in · the six verdicts

The two diamonds after RE-PROFILE in figure 1, and what each answer sends back. The agent asks one question — did DiscoPoP parallelize the lines that changed? — and the answer decides both whether the rewrite survives and what the model hears next. These mean opposite things, so a single “try again” actively misleads: telling a model to hunt for dependences when the dependence is already gone pushes it off a working transformation.

Why this step exists

Passing the gate proves a rewrite compiles and preserves output — that it is harmless, not that it is useful. Without this check the agent could print 1 accepted for a rewrite that parallelized nothing. Two benchmark cases proved it: bubble_sort and prefix_sum both produced rewrites that passed every gate stage and were reverted here, ending at 0 pragmas.

06 What each retry costs

budget · default 3

real attempts

One per genuine parallelization idea. Spent when a rewrite is semantically wrong, races, or fails to pay off.

build-retries · default 2

free build fixes

Apply and compile failures refund the slot — a typo says nothing about the idea. Capped so a model that cannot produce compiling code still terminates.

format retries · 2

free, inside one call

The reply was unusable — no diff, or the file left untouched in direct mode. Re-prompted without touching budget.

restructure-depth · default 0

how far the source may drift

Only the initial candidates may be rewritten. Loops exposed by a rewrite get Tier 1 alone, which is what makes the loop terminate.

Six of eight end faster; none produce wrong output, which is the property the correctness stage exists to guarantee. The two reverted cases are the hardest transformations in the set — an odd-even partition with re-derived bounds, and a parallel scan. In both, every rewrite passed the gate and was caught by the verification step: the agent declined rather than claiming a win it had not earned.
